# Clarity design mockups

Three standalone, static directions for the Dashboard and Reviews tabs. Each folder contains an `index.html` and a `style.css`. Open any `index.html` directly in a browser. The navigation links only jump between the two mockup sections; filters, metrics, and actions use illustrative data and are not connected to the app.

| Concept                                 | Direction                  | What it explores                                                   |
| --------------------------------------- | -------------------------- | ------------------------------------------------------------------ |
| [01 Porcelain](01-porcelain/index.html) | Warm, spacious, Apple-like | Focused action summary, calm review inbox, generous whitespace     |
| [02 Graphite](02-graphite/index.html)   | Executive, dark sidebar    | Strong hierarchy, serious operational tone, denser workspace       |
| [03 Ledger](03-ledger/index.html)       | Editorial, paper-like      | Table-first review scanning, restrained typography, clear evidence |

All three use the fictional Harbour House Hotel context and sample review wording. No build step, script, network resource, or backend is required.
